# PayTrack — HackCache '26

Problem statement: The Small Business Invoice Chase

PayTrack is a responsive browser-based invoice and payment tracking MVP for small businesses.

## Features
- Create customer invoices with amounts and due dates
- Automatic paid, pending and overdue status
- Summary dashboard
- Search and status filters
- Mark invoices as paid, delete entries
- Generate email reminders or copy reminder text
- Export invoice records to CSV
- Load sample demo data
- Persistent local browser storage

## Run
Open `index.html` in a modern browser. No dependencies or installation needed.

## Deploy
Upload this folder to a public GitHub repository. Enable GitHub Pages under Settings → Pages → Deploy from branch → main / root. Wait for the published URL.

## Scope / limitations
This is a working frontend MVP. Data is stored locally in the browser, not synced between devices. Reminders are drafts, not automatically sent. No authentication, backend, or real payment integration is included.
